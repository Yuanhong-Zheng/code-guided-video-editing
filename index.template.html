THE IDEA

A visible plan.
An editable program.

A coding agent observes the source video and edit request, then builds a procedural scene. Rendering the scene produces a proxy that expresses object placement, camera framing, and timing.

The frozen video model receives both the source and the proxy. Early-step guidance establishes the edited structure, while the source continues to anchor the final video.
